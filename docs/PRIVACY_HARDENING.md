# 隐私加固版使用说明

这组修改只收紧 Mac 本机接口、日志、短信保存和卸载清理，不改变模块通信协议、拨号、短信、eSIM 或网络模式切换的核心流程。

## 普通用户如何安装

1. 打开仓库的 **Actions** 页面，选择 **Build macOS package**。
2. 点击 **Run workflow**。版本标签保留默认值即可。
3. 构建完成后，下载页面底部的 `DJOneHub-macOS-...` 构建产物并解压。
4. 校验 DMG：在终端运行 `shasum -a 256 下载的.dmg`，结果应与同目录 `.sha256` 文件一致。
5. 打开 DMG，运行“安装 DJOneHub.command”。安装后按原来的方法使用菜单栏 App。

GitHub Actions 的手动构建会同时生成构建来源证明。它不能代替 Apple Developer ID 公证，但可以证明下载文件来自仓库中的这次构建。

## 第一次升级后的变化

- 后台会自动创建 `~/Library/Application Support/DJOneHub/api-token`。App 会自行读取，不需要手工配置。
- 旧版菜单栏 App 无法调用新后台，因此必须把后台和 App 一起升级，不能只替换其中一个。
- 已接收短信会保存到 `sms-cache.json`。文件只允许当前 macOS 用户读取，最多保留 500 条。
- AT 调试入口只允许只读诊断命令；写配置、重启、拨号等操作仍由 App 的专用按钮完成。

## 注意事项

- 不要分享 `api-token`、`sms-cache.json` 或完整日志。这些文件分别相当于本机接口钥匙、短信内容和设备诊断记录。
- 本项目仍采用免费、自签名方式构建，没有付费 Developer ID 和 Apple 公证。首次打开时 macOS 可能要求在“系统设置 → 隐私与安全性”中确认。
- 卸载时先连接模块并保持 Mac/ADB 模式，再运行 DMG 内的卸载脚本。这样脚本才能同时移除模块上的启动项、服务、wake lock 相关状态、日志和备份。
- 如果卸载时模块未连接，Mac 端仍会卸载，但模块侧文件可能保留。重新安装同一加固版、连接模块后再运行一次卸载即可清理。
- 自动测试能验证编译、本机 API 和不依赖硬件的逻辑；真实通话、运营商 VoLTE、eSIM 写卡和不同固件仍必须在对应模块与 SIM 上实测。

## 回退

若需要回退，先用本加固版 DMG 内的卸载脚本清理 Mac 与已连接模块，再安装旧版。不要直接混用新后台与旧 App。
